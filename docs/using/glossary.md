dmsforall uses the words a Swiss garage uses every day. This page explains the ones that are not obvious, especially for a new apprentice. The same explanations appear as tooltips in the application.

| Term                         | Meaning                                                                                         | German                       | Italian                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------- | -------------------------- |
| **OR** (ordre de réparation) | The work file of one vehicle, from reception to handover. Also called a repair order.           | Reparaturauftrag (RA)        | ordine di riparazione (OR) |
| **MFK** (expertise)          | The official Swiss vehicle inspection (contrôle technique). Due at regular intervals.           | MFK (Motorfahrzeugkontrolle) | collaudo (MFK)             |
| **VN** (véhicule neuf)       | A new car, never registered before the sale.                                                    | Neuwagen (VN)                | veicolo nuovo (VN)         |
| **VO** (véhicule d'occasion) | A used car, already driven, sold by the garage or taken in part exchange.                       | Occasion (VO)                | veicolo usato (VO)         |
| **QR-facture**               | The Swiss payment slip with a QR code, scanned in e-banking to pay an invoice.                  | QR-Rechnung                  | QR-fattura                 |
| **Avoir**                    | A credit note that cancels all or part of an issued invoice. An issued invoice is never edited. | Gutschrift                   | nota di credito            |

## Notes for the team

- The abbreviation of a repair order in German is **RA** and in Italian **OR**. Use these forms consistently in new text.
- Only the first use of "OR" on a screen needs the full words "ordre de réparation" in the text itself. Everywhere else, the tooltip carries the explanation.
- Use "Créer un OR" for every action that opens a new repair order.
