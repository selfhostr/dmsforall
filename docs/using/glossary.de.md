---
title: Glossar
description: Die Begriffe aus dem Garagenalltag in dmsforall mit ihren deutschen und italienischen Entsprechungen.
---

dmsforall verwendet die Begriffe, die eine Schweizer Garage täglich braucht. Diese Seite erklärt die, die nicht offensichtlich sind, vor allem für eine neue Lernende oder einen neuen Lernenden. Dieselben Erklärungen erscheinen als Hinweise in der Anwendung.

| Begriff                      | Bedeutung                                                                                                                  | Deutsch                      | Italienisch                |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | -------------------------- |
| **OR** (ordre de réparation) | Die Auftragsakte eines Fahrzeugs, von der Annahme bis zur Übergabe. Auch Reparaturauftrag genannt.                         | Reparaturauftrag (RA)        | ordine di riparazione (OR) |
| **MFK** (expertise)          | Die amtliche Fahrzeugprüfung in der Schweiz (contrôle technique). Sie ist in regelmässigen Abständen fällig.               | MFK (Motorfahrzeugkontrolle) | collaudo (MFK)             |
| **VN** (véhicule neuf)       | Ein Neuwagen, der vor dem Verkauf nie zugelassen war.                                                                      | Neuwagen (VN)                | veicolo nuovo (VN)         |
| **VO** (véhicule d'occasion) | Ein Occasionswagen, bereits gefahren, vom Betrieb verkauft oder in Zahlung genommen.                                       | Occasion (VO)                | veicolo usato (VO)         |
| **QR-facture**               | Der Schweizer Zahlungsschein mit QR-Code, der im E-Banking gescannt wird, um eine Rechnung zu bezahlen.                    | QR-Rechnung                  | QR-fattura                 |
| **Avoir**                    | Eine Gutschrift, die eine ausgestellte Rechnung ganz oder teilweise aufhebt. Eine ausgestellte Rechnung wird nie geändert. | Gutschrift                   | nota di credito            |

## Hinweise für das Team

- Die Abkürzung eines Reparaturauftrags lautet auf Deutsch **RA** und auf Italienisch **OR**. Verwenden Sie diese Formen in neuen Texten einheitlich.
- Nur das erste Vorkommen von «OR» auf einem Bildschirm braucht die ausgeschriebenen Worte «ordre de réparation» im Text selbst. Überall sonst liefert der Hinweis die Erklärung.
- Verwenden Sie für jede Aktion, die einen neuen Reparaturauftrag eröffnet, die Bezeichnung **RA erstellen**.
