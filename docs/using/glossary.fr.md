title: Glossaire
description: Les termes du garage utilisés dans dmsforall, avec leurs équivalents allemand et italien.
---

dmsforall utilise les mots qu'un garage suisse emploie tous les jours. Cette page explique ceux qui ne sont pas évidents, surtout pour un nouvel apprenti. Les mêmes explications apparaissent en infobulles dans l'application.

| Terme                        | Signification                                                                                              | Allemand                     | Italien                    |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------- | -------------------------- |
| **OR** (ordre de réparation) | Le dossier de travaux d'un véhicule, de la réception à la remise. Appelé aussi ordre de réparation.        | Reparaturauftrag (RA)        | ordine di riparazione (OR) |
| **MFK** (expertise)          | Le contrôle officiel des véhicules en Suisse (contrôle technique). À effectuer à intervalles réguliers.    | MFK (Motorfahrzeugkontrolle) | collaudo (MFK)             |
| **VN** (véhicule neuf)       | Une voiture neuve, jamais immatriculée avant la vente.                                                     | Neuwagen (VN)                | veicolo nuovo (VN)         |
| **VO** (véhicule d'occasion) | Une voiture d'occasion, déjà utilisée, vendue par le garage ou reprise en échange.                         | Occasion (VO)                | veicolo usato (VO)         |
| **QR-facture**               | Le bulletin de versement suisse avec un code QR, scanné dans l'e-banking pour payer une facture.           | QR-Rechnung                  | QR-fattura                 |
| **Avoir**                    | Une note de crédit qui annule tout ou partie d'une facture émise. Une facture émise n'est jamais modifiée. | Gutschrift                   | nota di credito            |

## Notes pour l'équipe

- L'abréviation d'un ordre de réparation est **RA** en allemand et **OR** en italien. Utilisez ces formes de manière cohérente dans les nouveaux textes.
- Seule la première occurrence de « OR » sur un écran a besoin des mots complets « ordre de réparation » dans le texte lui-même. Partout ailleurs, l'infobulle porte l'explication.
- Utilisez « Créer un OR » pour toute action qui ouvre un nouvel ordre de réparation.
