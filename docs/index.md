---

dmsforall is management software for Swiss garages and dealerships. It covers clients and vehicles, repair orders, time clocking, invoices with a Swiss QR-bill, parts and stock, used and new car sales, and tyre storage. It runs in a web browser, on a server that you operate.

Start with one of these pages:

- **Install it:** [Quick start](get-started/quick-start.md), then [Installation](get-started/installation.md).
- **Set it up for a garage:** [Your first garage](get-started/first-garage.md).
- **Use it day to day:** [Repair orders](using/workshop-orders.md), [Quotes and invoices](using/quotes-and-invoices.md), [Payments](using/payments.md).
- **Look something up:** [Configuration](reference/configuration.md), [Roles and rights](reference/roles-and-rights.md), [API](reference/api.md).

The interface is available in French, German and Italian. These pages are in English, so screen labels are given in English here. Your interface shows them in the language you chose.

:::caution
dmsforall is in alpha. Development is paused for now. The code, images and docs stay available, but do not expect new features or quick fixes. A live demo is available at https://dmsforall.selfhostr.io/demo/. Read the [limits in the README](https://github.com/selfhostr/dmsforall#limits) before you use it for real invoices.
:::
