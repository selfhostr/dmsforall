dmsforall ist eine Verwaltungssoftware für Schweizer Garagen und Autohäuser. Sie umfasst Kunden und Fahrzeuge, Reparaturaufträge, Zeiterfassung, Rechnungen mit Schweizer QR-Rechnung, Ersatzteile und Lager, den Verkauf von Neu- und Occasionswagen sowie die Einlagerung von Reifen. Die Software läuft im Webbrowser, auf einem Server, den Sie selbst betreiben.

Beginnen Sie mit einer dieser Seiten:

- **Installieren:** [Schnellstart](get-started/quick-start.md), danach [Installation](get-started/installation.md).
- **Für eine Garage einrichten:** [Ihre erste Garage](get-started/first-garage.md).
- **Im Alltag verwenden:** [Reparaturaufträge](using/workshop-orders.md), [Offerten und Rechnungen](using/quotes-and-invoices.md), [Zahlungen](using/payments.md).
- **Nachschlagen:** [Konfiguration](reference/configuration.md), [Rollen und Rechte](reference/roles-and-rights.md), [API](reference/api.md).

Die Oberfläche ist auf Französisch, Deutsch und Italienisch verfügbar. Die Bezeichnungen der Bildschirme werden auf dieser Seite so angegeben, wie sie in der deutschen Oberfläche erscheinen. Ihre Oberfläche zeigt sie in der Sprache, die Sie gewählt haben.

:::caution
dmsforall befindet sich in der Alpha-Phase. Eine Live-Demo ist unter https://dmsforall.selfhostr.io/demo/ verfügbar. Lesen Sie die [Einschränkungen in der README](https://github.com/selfhostr/dmsforall#limits), bevor Sie die Software für echte Rechnungen einsetzen.
:::
